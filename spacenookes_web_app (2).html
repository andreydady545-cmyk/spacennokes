Как выложить сайт SpaceNookes на весь Интернет за 2 минуты

Подробная инструкция без скачивания сторонних программ — прямо через браузер.

1

Создайте аккаунт на GitHub

Перейдите на официальный сайт github.com. Если у вас нет аккаунта, нажмите Sign up и зарегистрируйтесь. Если есть — войдите в систему (Sign in).

2

Создайте новый репозиторий (хранилище)

В правом верхнем углу сайта нажмите на плюс (+) и выберите New repository.
• В поле Repository name напишите название, например: spacennokes
• Выберите пункт Public (Публичный), чтобы сайт был виден всем в интернете.
• Нажмите зеленую кнопку Create repository в самом низу.

3

Загрузите файл вашего сайта

На странице созданного репозитория найдите фразу: «get started by creating a new file or uploading an existing file».
Кликните на синюю ссылку upload an existing file.
Перетащите ваш готовый файл index.html в окно браузера, прокрутите вниз и нажмите зеленую кнопку Commit changes.

4

Включите GitHub Pages

В верхнем меню репозитория перейдите во вкладку Settings (Настройки).
В левом боковом меню выберите пункт Pages.
В разделе Branch выберите ветку main (или *master*) и нажмите Save.

✓

Готово! Сайт в интернете

Через 30–60 секунд обновите страницу — сверху появится ваша постоянная ссылка в формате https://ваш-логин.github.io/spacennokes/. Отправляйте её друзьям!
